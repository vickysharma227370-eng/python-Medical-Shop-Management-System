Title: Medical Shop Management System (Class 11)
Description:
Built the data management layer (using MySQL) as part of a 3-member team developing a medical shop management system;
teammates handled the Tkinter-based graphical interface. My focus was structuring and managing the underlying data using core DSA concepts.
In this project we tried to find the solution to the manufacturers and the medical shops owners about the medicines details to be enclosed at one place so that the emdicines data are structured and organised properly. 
We, made this software so that owners can track in real-time the complete details of medicines such as medicine expiration date, manufacturer, data of number of patients using that medicine, prescription of doses, sellers and buyers details, and everything that which medicine is in stock or not , etc.
This was an introduction to our project Medical Shop Management.
I hope this description would help the viewers to understand an outline about our project
